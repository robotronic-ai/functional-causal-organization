# Structural Certification

## 1. Why exact fit is not enough

If a representation is injective on the observed domain, every target factors through it. This is the **injectivity trap**. A useful factorization test therefore requires non-trivial fibers.

## 2. Lambda Certification levels

- **LC0 — Formal fit**: no contradiction on observed points; fibers may be trivial.
- **LC1 — Fiber tested**: at least one non-trivial fiber has been tested.
- **LC2 — Fiber exhausted**: every fiber in a finite declared envelope has been checked.
- **LC3 — Groupoid generated**: target-blind causal morphisms generate all fibers and target invariance is established on those morphisms.
- **LC4 — Closed causal certification**: the relevant closed causal kernel is conjugate/descended, so the certificate transports across declared compositions and horizons.

## 3. Generator certificates

A generator is admissible only if its justification can be written without using the target `Lambda`.

A certificate should record:

- causal context,
- source and target realizations,
- state/intervention/boundary maps,
- commuting-kernel condition,
- proof that it stays within one candidate fiber,
- temporal scope: one horizon, bounded horizon, or full closed dynamics.

## 4. Fiber generation

If a target-blind generator set connects every point in each fiber and every generator preserves the target, the whole fiber is certified by transitivity.

The minimal number/cost of generator types is a **proof complexity** measure, not an ontological decomposition of the target.

## 5. Composition

Closed quotients compose. Exact groupoid certification composes when quotient-level generators admit causal lifts back to the original system.

Minimality does not generally compose: a distinction needed at an intermediate stage can become irrelevant for the final target.
