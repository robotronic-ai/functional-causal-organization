# Exploratory Co Search 11

## Purpose

Find a candidate as quickly as possible after Fidelity-First 10 showed that PCA20 is a high-fidelity target-blind representation but the first qualified K16 quotient still has four behavioral collision pairs.

This phase is explicitly target-informed and exploratory. Any selected candidate must be tested on a new independent validation panel before it can be treated as transported evidence.

## Frozen representation

Search 11 does not invent a new internal measurement. It reuses the exact rich-proxy standardizer and PCA20 representation already frozen by Fidelity-First 10.

The rich proxy is the 288D operation x source-address x target-address x horizon x internal-metric trajectory used by the cross-target active-channel campaign.

## Search order

1. Refit deterministic K18 and K20 quotients on the already frozen PCA20 scores and inspect closure.
2. K16 is also retained as a baseline.
3. Only if a fidelity-qualified pure quotient still collides, allow collision-guided local splits inside the colliding base fibers.
4. Local split rules use only PCA20 coordinates and deterministic scalar thresholds. They do not add a new primitive component.

## Candidate rule

A construction candidate is useful only if all are true:

- behavioral collision pairs = 0;
- nontrivial coverage >= 0.20;
- within-fiber rich distortion <= 0.20.

Candidate ranking prefers, in order:

1. higher nontrivial coverage;
2. lower within-fiber rich distortion;
3. fewer local split fibers;
4. smaller base K.

## Epistemic status

Behavioral targets are used to choose among fidelity-qualified quotients and, when required, to select local split rules. Therefore the selected object is target-informed by construction. A clean construction result is not confirmatory evidence.

A fresh 64-system Validation 11 is required. The candidate, PCA basis, K-means centers, and local split thresholds are frozen before Validation 11 and cannot be refit on that panel.
