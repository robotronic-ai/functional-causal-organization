## Evaluation rule

The behavioral target is used only after every representation label has been built.

A screen is admissible only if it satisfies all of the following:

- zero heterogeneous collision pairs;
- non-trivial coverage at least `0.20`;
- fiber fraction at most `0.80`;
- normalized sufficiency loss equal to zero;
- AMI above the screen-specific 95th percentile of 1000 target permutations;
- AMI above the 95th percentile of the **maximum AMI over all 66 declared screens** under the same 1000 target permutations.

The last condition is a family-wise forking-path control for this adaptive development search.

Among admissible screens, select the coarsest partition first: fewer fibers, then fewer components. Remaining ties prefer coarser continuous resolution, then shallower R rank depth.
