# Joint Relational Active-Kernel Screen 06

## Purpose

Validation 05 refuted the frozen hybrid amplitude/codebook descriptor while achieving 56.25% nontrivial coverage. The next exploratory step therefore changes the representation rather than adding more quantization levels.

The screen asks whether target-blind relational structure already present in the active-kernel panels is a better compact invariant.

## Source data

The screen combines two active-kernel panels already executed under the same measurement contract:

- 32-system active-kernel panel;
- 64-system Validation 05 panel.

No new Qwen execution is required for the screen.

## Fixed target-blind feature families

Each family is built from relations among H1/H2/H3 rather than raw amplitudes. The available primitives are:

- address argmax for a fixed operation, experimental intervention, horizon, and internal metric;
- full H1/H2/H3 rank order for selected metrics;
- winner between `ZERO_SUFFIX` and `HEAD_ROTATE` using a fixed 5% relative equivalence margin;
- temporal trend from horizon 1 to horizon 2 using the same fixed 5% relative equivalence margin.

The feature definitions do not use behavioral outcomes. Behavioral outcomes are used only to compare the frozen family alternatives during this exploratory screen.

## Families

The screen compares SUBSTITUTE-only and all-operation variants at several levels of relational detail, from final-hidden argmax through multi-block relational topology.

## Useful-candidate criterion

A candidate is useful only if both conditions hold on the combined 96-system source set:

- zero functional collision pairs;
- at least 20% of systems are in nontrivial fibers.

A closed but injective or nearly injective representation is not promoted.

## Fresh validation

If the screen returns `USEFUL_EXPLORATORY_CANDIDATE`, Validation 06 freezes the selected family and applies it without tuning to 96 fresh systems.

If no useful candidate exists, the current same-address active-kernel measurement is considered insufficient for this closure target. The next measurement should then expose a cross-address source-to-target response channel rather than continue refining the same descriptor family.
