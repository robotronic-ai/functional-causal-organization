# Naming Note

`FCA-Bench` is the short name used in the code and in the manuscript.

The expansion used is:

**Functional Causal Access Benchmark**

The word `Causal` is intentional. In this benchmark it refers to interventionally testable access: whether information, goals, state variables, control signals, or internal resources can influence, update, suppress, route, preserve, or release other parts of the evaluated system under controlled interventions.

The name does **not** mean that FCA-Bench measures general intelligence, model sophistication, phenomenal consciousness, or a scalar degree of consciousness. Behavioral evidence and causal/interventional evidence are reported separately and are never merged into an official scalar.

The command-line suite name is `causal`. The internal label `mechanistic` is kept as a compatibility alias for result readers.

Before public release, the acronym should still be reviewed for discoverability. As of September 2026, `FCA Bench` is also used publicly by an unrelated financial-crime agent benchmark. The exact expansion `Functional Causal Access Benchmark` is more distinctive, but the short name can still create search and citation ambiguity.
