## 2. Finite-horizon behavioral compilation theorem

Consider any causal finite-horizon transducer with horizon \(H\):

\[
z_{t+1}=F_t(z_t,u_t),
\qquad
y_t=G_t(z_t,u_t),
\qquad
t=0,\ldots,H.
\]

For every input prefix:

\[
u_{\le t}
=
(u_0,\ldots,u_t),
\]

the output \(y_t\) is a well-defined function or conditional distribution of
that prefix.

Therefore there exists an acyclic finite-horizon implementation with fresh
time-indexed computation blocks:

\[
\tilde y_t
=
\tilde G_t(u_{\le t},\xi_t)
\]

that reproduces the same conditional output law for every admissible input
history, without any internal variable returning to the same declared active
role across time.

For deterministic systems, \(\xi_t\) is unnecessary.  For stochastic systems,
fresh exogenous randomness can reproduce the conditional kernel.

Hence any finite behavioral battery that depends only on the input/output law
over a finite horizon is compatible with a causally acyclic implementation.

### Consequence

A finite external access-consequence battery cannot, by itself, establish:

\[
R(k)>0.
\]

More generally, external behavioral equivalence does not identify the internal
causal organization.

This theorem does **not** say recurrence is irrelevant.  It says recurrence
cannot be inferred from finite extensional behavior alone.
