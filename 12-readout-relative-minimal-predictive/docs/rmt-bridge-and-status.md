# RMT bridge and status/handoff

Source material: `RMT_BRIDGE.md` and `STATUS_AND_HANDOFF.md`.

## What the predictive theorem measures

The readout-relative predictive realization characterizes what future trajectories
are available to a declared class of readouts. This is fundamentally a
**capacity / predictive-structure** statement. It does not by itself establish that a
particular readout is causally used by the system.

## Capacity versus realized causal binding

Keep the distinction: `A_cap` = access attainable by some admissible reader;
`A_real` = access produced by the reader / causal binding actually installed. A prior
finite campaign in this project (the ID/SWAP finite witness) established that
identical internal dynamics and identical access capacity can coexist with different
realized access when the installed readout is changed.

## The A5 retarget result (external, referenced here for context)

This bundle's `external_inputs_registry.json` records that it draws on an external RMT
A5 v0.5 causal-retargeting result (hashes only — the underlying result files are not
part of this bundle). That result reports:

- status: `RMT-A5V05-CAUSAL-RETARGET-PASS`;
- base original accuracy: `0.982421875`;
- target donor-following accuracy: `0.966796875`;
- target original accuracy after swap: `0.033203125`;
- mean sham donor-following accuracy: `0.017578125`;
- target minus mean-sham donor-following: `0.94921875`;
- one-sided bootstrap lower 95% bound: `0.927734375`;
- holdout spent: `true`; retuning on that holdout forbidden: `true`.

This is evidence for **realized causal binding** under its own frozen intervention
protocol, from a separate campaign in this project. It is cited here only as context
for the capacity/realized-use distinction above, and it must not be re-described as a
proof of the predictive-realization theorem in this bundle — the two are independent
lines of evidence about different things.

## Proposed future bridge (not yet done)

A useful future RMT target: (1) identify a low-dimensional predictive state using
calibration data only; (2) fit a single transition operator on that state; (3) predict
declared readouts at held-out horizons; (4) compare predictive capacity with causal
retarget / swap results. This would explicitly separate predictive capacity, stable
transport, and realized causal binding. Not attempted in this bundle.

## Current status and handoff

**Conclusion.** The strongest current candidate is not a scalar access statistic and
not a table of future outputs — it is the readout-relative minimal predictive
realization generated by Koopman closure of the declared readout space, keeping two
minimal objects distinct: `Q_{E,D}` (coarsest deterministic predictive quotient) and
`V_{E,D}` (minimal reachable linear realization).

**Core theorem status.** The archive contains a constructive proof sketch for exact
prediction, deterministic quotient coarseness, universal surjection from any
reachable exact linear realization, minimal dimension, uniqueness up to isomorphism,
and generalized Hankel rank characterization. Status label: `THEORETICAL-DERIVATION`.
**The result has not been externally peer reviewed.**

**Exact finite checks — all `PASS`** (see `docs/finite-verification-results.md` for
full detail): arbitrary-readout four-state orbit corollary; restricted-readout
nonlinear four-state theorem audit; all 512 U0-style `3x3` binary linear systems;
controlled three-state/two-generator exhaustive universe (5,103 cases); finite
controlled Markov expectation audit in exact rational arithmetic (243 cases).

**What is no longer claimed** (explicit retractions carried from the source
material's own handoff notes, per this project's "never hide a found defect"
discipline): do not claim that a target-indexed object such as a complete
realized-output table is a nontrivial sufficient statistic merely because it has zero
heterogeneous fibers; do not claim that a previous `R_{E,D}` table (from earlier work,
not part of this bundle) resolved the access line — it was a target re-encoding; do
not claim that the stochastic expectation-level construction already proves full
probabilistic bisimulation.

**What survives from prior work.** `A_cap` and `A_real` are distinct; a prior U1
stable-factor quotient is an exact task-specific projection for its declared
common-reader access test; the organization/access relation is best represented as a
co-factorization through a richer causal object, not a direct scalar map
`C_O -> A`; the RMT A5 v0.5 result (above) supplies independent evidence for realized
causal binding under its own frozen retarget protocol.

**Recommended next step.** Formalize the full path-law version separately from
expectation-level prediction, preferably through a separating family of cylinder
observables or a direct probabilistic-bisimulation statement (see
`docs/stochastic-extension-and-open-questions.md`).
