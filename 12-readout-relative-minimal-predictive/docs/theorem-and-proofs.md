# Theorem and proofs: readout-relative minimal predictive realization

Source material: `THEOREM_SPEC.md` and `PROOF_SKETCH.md`.

## 1. Deterministic setup

Let `X` be a set, `Z` a source-content set, `E : Z -> X` a source interface,
`F : X -> X` a deterministic time-homogeneous transition, `K` a field, and
`D subset K^X` a `K`-vector space of admissible scalar readouts. The reachable set is
`R_E = { F^k(E(z)) : z in Z, k >= 0 }`. The Koopman operator is `U_F d = d o F`. The
**predictive readout closure** is

```
W_{F,D} = span{ U_F^k d : d in D, k >= 0 },
```

the smallest `U_F`-invariant vector space containing `D`.

## 2. Behavioral predictive equivalence

For `x, y in R_E`, define `x ~_D y` iff `d(F^k(x)) = d(F^k(y))` for every `d in D` and
every `k >= 0` — equivalently, `f(x) = f(y)` for every `f in W_{F,D}`.

**Proposition A (predictive congruence).** `~_D` is `F`-invariant:
`x ~_D y => F(x) ~_D F(y)`. *Proof.* For `f in W`, Koopman invariance gives
`U_F f in W`, hence `f(F(x)) = (U_F f)(x) = (U_F f)(y) = f(F(y))`; so `F(x) ~_D F(y)`.
Therefore `F` descends to a well-defined transition on `Q_{E,D} = R_E / ~_D`.

**Proposition B (coarsest deterministic quotient).** Any equivalence `~` on `R_E`
preserving every future declared readout (`x ~ y => d(F^k(x))=d(F^k(y))` for all
`d, k`) satisfies `x ~ y => x ~_D y`. So `Q_{E,D}` is the coarsest deterministic state
quotient preserving all future declared readouts — any valid quotient equivalence is
finer than `~_D`.

## 3. Minimal linear predictive realization

For `x in R_E`, define `epsilon_x in W_{F,D}*` by `epsilon_x(f) = f(x)`, and
`V_{E,D} = span{ epsilon_x : x in R_E }`. Because `W_{F,D}` is Koopman-invariant, the
dual Koopman operator maps `epsilon_x -> epsilon_{F(x)}`; define
`A_pred = U_F* |_{V_{E,D}}`, source embedding `eta(z) = epsilon_{E(z)}`, and output
functionals `c_d(v) = v(d)` for `d in D`.

**Theorem 1 (exact predictive realization).** For every `z in Z`, `d in D`, `k >= 0`:

```
c_d A_pred^k eta(z) = d(F^k(E(z))).
```

*Proof.* `c_d(A_pred^k eta(z)) = (U_F^{k*} epsilon_{E(z)})(d) = epsilon_{E(z)}(U_F^k d)
= (U_F^k d)(E(z)) = d(F^k(E(z)))`. So `(V_{E,D}, A_pred, eta, {c_d})` exactly generates
every future trajectory observable by the declared readout class.

## 4. Minimality among reachable linear realizations

Let `(S, B, eta', {c'_d})` be any exact linear realization over the same field with
`S = span{ B^k eta'(z) }` (reachable) and `c'_d B^k eta'(z) = d(F^k(E(z)))` for every
`d, z, k`.

**Theorem 2 (universal quotient map).** There is a unique surjective linear map
`P : S -> V_{E,D}` with `P(B^k eta'(z)) = epsilon_{F^k(E(z))}`, intertwining the
dynamics (`P B = A_pred P`) and preserving outputs (`c'_d = c_d P` on `S`).

*Well-definedness proof.* Suppose `sum_i a_i B^{k_i} eta'(z_i) = 0` in `S`. Apply
`c'_d B^n` for arbitrary `d in D`, `n >= 0`: `sum_i a_i d(F^{n+k_i}(E(z_i))) = 0`. This
says the candidate image relation annihilates `U_F^n d` for every `n`, i.e. every
function generating `W`, so `sum_i a_i epsilon_{F^{k_i}(E(z_i))} = 0` in `W*`. Hence
`P` is well defined; it is surjective because `V_{E,D}` is spanned by the images of
reachable generators, and intertwining/output-preservation follow directly on
generators.

**Corollary 2.1 (minimal dimension).** `dim(V_{E,D}) <= dim(S)` whenever finite (a
surjection cannot increase dimension).

**Corollary 2.2 (uniqueness).** Any two reachable exact realizations of minimal
dimension are linearly isomorphic through an intertwining map preserving source
embeddings and outputs (a surjection between equal finite dimensions is an
isomorphism).

## 5. Hankel characterization

Define the generalized future-readout Hankel operator
`H_F[(d,n),(z,k)] = d(F^{n+k}(E(z)))`, rows ranging over declared readouts and future
delays, columns over source/time pairs. When the relevant spans are finite-dimensional,
`rank(H_F) = dim(V_{E,D})` — the row span is generated by `W_{F,D}`, the column span by
the reachable predictive states `V_{E,D}`, and the rank of this bilinear pairing equals
`dim(V_{E,D})` after quotienting any functions in `W` vanishing on all reachable states
(automatic here, since `V_{E,D}` is defined inside `W*` using only reachable
evaluations).

## 6. Relation between the two minimal objects

`x -> epsilon_x` is constant exactly on behavioral equivalence classes, so `Q_{E,D}`
injects into `V_{E,D}` as a set of predictive states. But these predictive state
vectors can be **linearly dependent**, so `Q_{E,D}` is minimal among deterministic
state quotients while `V_{E,D}` is minimal among reachable linear realizations — these
are different minimality claims and must not be conflated (see
`docs/finite-verification-results.md` for the exhaustive finite check that exhibits
this gap directly).

## 7. Corollary: arbitrary readouts on a finite state space

If `X` is finite and `D = K^X` (all scalar functions), then `W_{F,D} = K^X`; distinct
reachable states have distinct, linearly independent evaluation functionals. So
`Q_{E,D} = R_E` (up to state renaming) and `dim(V_{E,D}) = |R_E|` — the deterministic
quotient is exactly the reachable orbit machine. Exhaustively verified, 0 failures on
3,840 cases (`results/all_readouts_orbit_corollary.json`).

## 8. Corollary: linear dynamics and linear readouts

For finite-dimensional `X`, `F(x) = Ax`, and `D subset X*`:
`W_{F,D} = span{ d A^k : d in D, k >= 0 } subset X*`. Let `R = span{A^k E(z)}` be the
reachable subspace and `N = R cap W_{F,D}^perp` the reachable unobservable subspace.
Then `V_{E,D} ~= R/N`, so `dim(V_{E,D}) = dim(R) - dim(N)`, equal to the rank of the
associated block Hankel matrix. Exhaustively verified, 0 failures on all 512 binary
`3x3` dynamics (`results/u0_linear_corollary.json`).

## 9-10. Controlled and observable-semigroup generalizations

Extending to a family of deterministic generators `F_u` (Section 9) and to a general

## 11. Scope limitation

This is an exact result about future readout trajectories under the declared readout
class. By itself it does not establish realized causal use of a readout, functional
consciousness, scalar `C_O` sufficiency, stochastic full-path equivalence, or
phenomenal consciousness.

## Why this is not target re-encoding

The predictive state does not contain a table indexed by a chosen future target. It is
generated from the transition law, the source interface, the declared readout space,
and closure under composition; future values are produced by repeatedly applying
`A_pred`, not looked up. A candidate that directly stores `d(F^k(E(z)))` for every
target cell is not an explanatory compression and is rejected by the target-reencoding
guard (`docs/protocol-and-guardrails.md`, Gate G1-G2).
