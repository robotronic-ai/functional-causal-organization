# 14 — Four-Family Closure and the Compression Limit Theorem

## What this folder is

This folder addresses one specific question a reviewer will ask about the
manuscript's bridge hypothesis `H_CO⁺`: *why should residual variation in
functional access A* be attributed to active causal organization 𝒞 at all,
rather than to knowledge, embodiment, or something not yet named?* And,
separately: *even granting that, why should the four declared scalars of
C_O = (Γ, Δ, R(k), Λ) be trusted to capture that variation?*

These are two different questions, and this folder keeps them separate on
purpose.

## Contents

- `docs/four-family-axis-completeness.md` — the axis-completeness argument
  (Ψ = (𝒮, 𝒢, 𝒞, 𝒪) is complete; no fifth family; O is not part of 𝒞).
  **Reported from a separate conversational record, not independently
  re-verified with frozen artifacts in this archive edition** — read it as a
  narrative motivation, not as an executed result.
- `docs/compression-limit-theorem.md` — a short, self-contained, fully
  proved theorem: axis-completeness (localization) does **not** imply
  that a non-injective compact profile is sufficient to predict A*.
  This is the logical hinge between this folder and folder `15`.
- `docs/claim-ladder.md` — a seven-rung ladder (L0–L6) stating precisely what
  is proved, what is finitely supported, what is refuted, and what remains
  open, adapted to this manuscript's C_O/A*/A†_I/H_CO⁺/H_N,I notation.
- `results/STATUS.json` — machine-readable status/verdict summary for the
  three items above.

## Reading this folder honestly

Only `compression-limit-theorem.md` is a self-contained proof verifiable from
this folder alone. `four-family-axis-completeness.md` is explicitly flagged
as unverified-in-this-archive narrative. `claim-ladder.md` borrows its rung
verdicts (L3 not established/false, L4 refuted) from the frozen finite
witnesses documented in folder `15`; it does not re-derive them here.

## Manuscript consequence

Do not claim the four-family ontology proves `C_O ⟹ A*`. Do claim it
motivates 𝒞 as the location of residual functional-access variation, and
that C_O is a compact, falsifiable construct hypothesis for predicting the
functional consequences of access — see `docs/claim-ladder.md`, final
section, for the exact recommended wording boundary.
